## 実装済みの中心経路

支払・利用実態 → 制作物への配分 → 複数年度の製作原価 → 取得価額 → 適用可能な方法 → 選択方法の年度額 → 残高 → 年度資料 → 翌年度・訂正・相談。

不明額は0円に変えず、元費用・原価・取得価額・年度費用を重複計上せず、試算と採用版を分離する。未送信控えの復旧だけで自動再送・採用しない。

「PCとデータ」では、各PCの履歴を1台から読み取る方法と、DevTaxのDBを新規保存先へbackup/restoreする方法を分離する。現在DBの上書きや切替え、クラウド同期、複数PC同時編集はしない。元ログ・証拠原本・ブラウザの未送信控え・外部アプリ設定は移行bundleに含めない。

## 未対応・未完了

税額算定、電子申告、所得区分の自動確定、特殊償却等の全範囲への対応を完成済みとしない。今回のパッチは、後続の共通事実・タイムライン、取込・訂正、例外計算の拡張を完了したものではない。

実ブラウザでの保存を伴う T03〜T14 と、同一候補での Windows・実共有フォルダ確認は別途必要。旧候補の実機成功を現行候補の成功へ転用しない。
