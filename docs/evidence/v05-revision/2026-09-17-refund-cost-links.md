# 2026-09-17 返金と実際に使用した原価の照合

基点: main `18884022ac78b940cd0efd36d7e5b3793a263772`。W06の返金・残高対応を継続。新規ブランチ・DBテーブル・保存APIは追加しない。

## 修正

従来の返金照合は、減少の種類・日付・金額・根拠IDを比較していた。根拠IDに元費用を書き込んでも、実際に減少した原価が別費用であるケースを検出できなかった。

年度資料の生成で既に算定する `balanceLotTrace` と `linkedCosts` を同じ参照照合へ渡す。原価を二度計算する機構は追加しない。返金元の原額・期間・契約、原価の費用年と寄与ID、使用額を照合する。複数出典の一つの原価を、出典ごとに全額へ読み替えない。原価未確定は未判断のまま保存でき、本人が残高減少と対応済みとする年度採用だけで整合を確認する。

同じ原額に対応する複数年度の原価は合算できる。将来の返金は過年度資料を止めず、無関係な未追跡残高をこの照合だけで一律停止しない。通常の残高入力では既存の軽い参照照合を維持する。旧採用版を読込み時に再検査・再計算する変更ではない。
