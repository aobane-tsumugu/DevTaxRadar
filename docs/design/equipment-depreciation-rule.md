# 設備の普通償却を費用基礎へつなぐ契約

設備の購入額、設備全体の普通償却額、業務分、制作物へ組み入れる額、当年必要経費、未償却残高を別々に扱う。目的は当年の説明と翌年への引継ぎであり、取得額を年数で割った数字を費用として採用することではない。

## 根拠と確認範囲

2026-09-08に以下の一次資料を確認した。方法を実装しても、入力した設備にその方法・耐用年数を適用できると自動認定したことにはならない。

| 根拠 | 計算への反映 |
| --- | --- |
| [国税庁 No.2106](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/2106.htm) | 2007-04-01以後取得の普通定額法。取得価額×率、年途中の月割。有形設備の償却限度は取得価額から1円を控除した額。無形資産とは分離 |
| [令和7年分・収支内訳書の書き方（不動産所得用）](https://www.nta.go.jp/taxes/shiraberu/shinkoku/tebiki/2025/pdf/019.pdf) 4・8ページ | 取得/使用月の月割に関する記載と、定額法の償却率表2〜50年。表はPDFの画像と抽出本文を照合。不動産所得の適用条件を開発業務へ移植する根拠にはしない |
| [確定申告書等作成コーナー・減価償却費の端数処理](https://www.keisan.nta.go.jp/r7yokuaru_sp/aoiroshinkoku/hitsuyokeihi/genkashokyakuhi/scid1736.html) | 個人の作成コーナーに合わせる円未満切上げ。法人の償却限度額計算へ共用しない |

率表の版は2025年、実装の確認日は2026-09-08。算式の根拠と個々の資産の適用条件は別々に更新・確認する。

## 実装した計算

[equipmentDepreciation.ts](../../src/core/equipmentDepreciation.ts)は、確認した入力を前提とする純粋な試算関数。対象は個人・有形設備・普通定額法・転用なし・年末まで継続利用・特別調整なし。旧方法、定率法、転用、年途中の終了/中断、特別償却、資本的支出等の調整は理由付き未対応とする。未知の条件をこの前提に自動置換しない。

| 入力/分岐 | 実装した挙動 | 接続時に必要な確認 |
| --- | --- | --- |
| 取得価額・取得日・業務利用開始 | 不明は計算しない。利用開始が取得前なら矛盾 | 付随費用・消費税処理を含む取得価額の範囲と原本 |
| 方法・理由・耐用年数 | 方法未確認は事実不足。表の範囲外は未対応。法定率を整数/1000で保持 | 設備区分・中古条件・方法の継続性・選択/届出・根拠 |
| 月数 | 当年の開始月から12月まで。年末継続を明示した入力だけを使用 | 終了・中断・転用の期間モデル。取得日で開始日を補わない |
| 前年残高 | 当年取得以外は前年末の設備全体残高と参照先を要求。年違い・取得額超過・0円は矛盾 | 実際の採用版と設備ID・前年・設備全体額の照合。自由文字の参照先だけでは未検証 |
| 端数・限度 | BigIntで取得額×整数率×月数、12000で除し円未満切上げ。残高1円を下限として当年額を制限 | 業務分/制作物配分では別の丸め契約と保存則が必要 |
| 出力 | 条件付き普通償却額・計算前基礎・償却後残高・率・月数・上限制御・算式。taxTreatmentVerified=false | 費用基礎への接続、按分、原価組入れ、年度採用との結合 |

missing-facts / unsupported / inconsistent / outside-periodはcalculation=null。条件付きの計算だけが数値を返す。償却済み1円の設備で当年額0円を返すことと、未算定を区別する。

## 検査

[テスト](../../tests/core/equipmentDepreciation.test.ts)は国税庁の100万円/10年の例、最終年99,999円・残高1円、その翌年0円、3年率0.334、12月31日開始の1か月分、円未満切上げ、入力不変、年ごとの金額保存、未確認と矛盾、未対応の非代用、安全整数上限の正確な中間演算、不正日付を検査する。

## 保存・画面・費用基礎への接続

EquipmentMethodsEditorから設備×年度の条件を入力し、PlanningSnapshot.equipmentMethodsとSQLite planning_equipment_methodsへ接続した。未登録・不足・未対応・矛盾は未算定のまま。入力条件が揃った場合だけ普通償却額を共通費用基礎へ渡す。条件は設備本体と同じtransactionで保存し、外部キー・年度/設備の一意制約・JSON schemaを検証する。既存DBは事前VACUUM退避後にテーブル追加する。

年度別の方法・確認事実は設備IDに関連付け、年度/設備キーによる競合比較、未完成入力控え、採用資料の固定入力、対象年の過年度差分に含む。取得額のExpenseSourceに普通償却CostBasisを結び、その額を業務/私用へ分けてから制作物へ配分する。期末の設備全体残高は、業務分の費用だけを引いた値で代用しない。制作物への組入れを、設備の購入と普通償却に重ねて費用計上しない。


年度別のallocationは業務割合・業務分の制作物割合・根拠を持つ。新規入力は割合null・根拠空欄で始める。業務割合または根拠が未確認なら設備年額全体を未配分、制作物割合だけ未確認なら業務分を未配分にする。確認した0%を未確認と混同しない。既存のallocation未登録記録は共通割合を使うことを表示する。明示した年度別割合を使う年度の過年度比較では、使っていない共通割合の変更だけを差分にしない。採用資料自体は当時の全入力を保持する。

allocation.taxUnitIdに年度別の制作物対応先を保持する。nullは未確認・未配分、フィールド欠落は旧設備の共通対応先の使用であり、区別して表示する。新規条件はnullから開始する。保存時に制作物の存在を検査する。明示済み年度の計算・過年度比較には共通対応先を使用せず、採用資料には当時の対応先を保持する。

前年残高の自由記述参照は採用版への自動照合が未接続。設備全体の償却後残高は算式へ表示するが、残高台帳や税務上の当年費用へ自動採用しない。年途中の終了・転用・特殊調整・他方法、割合の根拠内容の確認、同年度の複数制作物への配分も残課題。
