DevTax bundles PDF.js's legacy display library and legacy PDF worker from
the pinned npm distribution. The display library is bundled/minified by
Vite; the worker is copied as an application-local asset. No upstream
source files are modified. Only the text and document-info APIs are used.
No PDF viewer, scripting sandbox, external fonts, CMaps, or wasm assets
are loaded by receipt extraction.

The legacy bundles include core-js 3.50.0 polyfills.
